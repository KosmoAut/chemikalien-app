# Packliste – Chemikalien fotografieren

Android-App: Gebinde fotografieren, der Chemikalienname wird am Handy vom Etikett gelesen (Google ML Kit, offline, kostenlos) und in die Liste der Box eingetragen.

- Fotos: `Bilder/Chemikalien/<Box>/001_Aceton.jpg`
- Packliste (Word) + CSV: `Dokumente/Chemikalien/<Box>/`

**Installieren:** Unter „Releases“ die neueste `Packliste.apk` am Handy herunterladen und öffnen.
